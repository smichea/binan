# Biñan historical photographs and postcards: second research pass

Compiled 2026-11-14. This pass adds to `../archives/catalogue.md`. It does not repeat anything listed there: the Murillo Velarde 1734 map, the 18th-c. manuscript map, Atlas de Filipinas map 9, the AMS 1955/1956 sheets, the NARA c.1951 Biñan bridge photo, and the Laguna Copperplate.

Every file below was checked by eye. Its printed caption or archive metadata names Biñan/Binan (or "Biñang"), Laguna. None of them is Biñang in Bocaue, Bulacan.

Chapters: **Pre-colonial**, **Spanish colonial 1571–1898**, **American period 1898–1941**, **WWII 1941–45**, **Post-war/contemporary**.

Prefix `A_` = public domain. Prefix `B_` = rights pending or licence to be confirmed (permission request needed or advised).

## Leads not downloaded

1. ***Pictorial Album on Rizal*, José Rizal National Centennial Commission, 1962.** Commons file https://commons.wikimedia.org/wiki/File:Pictorial_album_on_Rizal_(JRNCC,_1962).pdf (176 pages, 100 MB; tagged PD-PhilippinesGov + PD-1996; source Biblioteca Virtual Miguel de Cervantes, https://www.cervantesvirtual.com/obra/pictorial-album-on-rizal-album-pictorico-sobre-rizal-876642/). Download failed: Wikimedia returned HTTP 429 (rate limit) on every attempt, and Cervantes Virtual returned 403. The Commons category "Images with extracted images" shows that some photos have already been extracted as separate files. Retry later from a normal browser and look for the Biñan pages (school site, Alberto house, plaza). Rights: works of the Philippine government carry no copyright (RA 8293 s.176), but **commercial use needs prior approval from the agency**. Successor: **National Historical Commission of the Philippines** (https://nhcp.gov.ph; use the contact address on that site, which was not verified here). Individual photos may be of private origin. Request wording: "We request permission to reproduce [page/plate] of the *Pictorial Album on Rizal* (JRNCC 1962) in a bilingual local-history book on Biñan, Laguna. Please confirm whether NHCP approval suffices or whether a separate photographer or owner must be contacted."
2. ***The Rizal Story in Pictures*: 21 postcards, ed. Austin Craig, Manila 1908.** Cited in *Rizal's Own Story* p. 123. The A1–A3 photos probably come from this postcard series; the A1 photo carries a postcard caption. Being published 1908, the series is PD. No digitised copy was found; search eBay, Delcampe, the Ortigas Foundation Library, and the UMich/LOC postcard holdings for "Rizal Story in Pictures" or "Rizal monument Biñan" postcards.
3. **Filipinas Heritage Library (Ayala Foundation), Retrato photo archive.** Web search shows Biñan photo records, including "Biñan plaza with calesas" (1971), a Biñan church marker, and Biñan items in the "WW2 – John Tewell Albums" category (e.g. Municipal Hall, plaza). Record pages: https://www.filipinaslibrary.org.ph/biblio/17972/, /17973/, /17974/, /10729/, /2900/, /2903/, /7111/, /7112/, /19271/, /23586/. They are JavaScript-rendered, so titles and dates could not be read automatically. Rights holder: Ayala Foundation / Filipinas Heritage Library. Order through each record's "Request for Reproduction" form; the booking page lists Retrato reproduction at PHP 200 per image. Group B.
4. **John Tewell postcard collection (Flickr).** No Biñan item was found by web search. Automated Flickr API search was not done (it needs an API key). Search Flickr by hand for user "John Tewell" + "Binan"/"Biñan"/"Laguna"; most of his uploads are "No known copyright restrictions" or "All rights reserved", so check each item.
5. **University of Michigan (quod.lib.umich.edu sclphilam / philpics).** Still blocked by a Cloudflare challenge (HTTP 403), even with a browser User-Agent. Search by hand.
6. **Ortigas Foundation Library image bank** (https://www.ortigasfoundationlibrary.com.ph/collections/image-bank-database/). It holds early Laguna postcards (San Pedro c.1910, "Town in the Province of Laguna"), but no Biñan card was found. Worth a manual search.
7. **Bureau of Public Works, *Quarterly Bulletin* (1913–15)** on IA (acw7643.*.umich.edu). The text mentions repair of the "Biñan Schoolhouse … the old hacienda building of the Biñan friar estate" and a projected Biñan market, but no Biñan photo was found in the OCR captions. The original volumes might have uncaptioned plates.
8. **Rizal's sketch map of the Laguna lake district** (Craig 1913, p. 73, leaf n100 of cu31924023255213). It is a drawing, PD, but the labels are illegible at scan resolution. Not downloaded.
9. Still open from the first pass: NARA RG 18-AA "Airscapes" Luzon (about 83 unchecked frames), AMS sheet 3263 II, and the Encarnación Alzona high-res portrait.
